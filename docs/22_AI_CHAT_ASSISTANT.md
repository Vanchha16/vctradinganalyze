# AI Chat Assistant

Version: 1.0

---

# 1. Objective

The AI Chat Assistant provides users with conversational access to the platform's market intelligence.

It answers questions using structured data generated by internal engines.

It does NOT invent market data.

It does NOT provide financial guarantees.

It explains evidence.

---

# 2. Responsibilities

The assistant shall:

- Answer market questions
- Explain AI recommendations
- Compare assets
- Explain technical indicators
- Explain SMC concepts
- Explain economic events
- Summarize market conditions
- Answer platform-related questions
